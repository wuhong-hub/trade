# astock 策略研究工作日志

> 用途：记录每一次策略迭代的假设、数据证据、结论与决策。新会话读本文件即可接续工作。
> 更新规则：每完成一个阶段，追加记录（日期、假设、证据、结论、commit），并更新"当前系统配置"。

## 系统简介

A 股量化推荐 CLI（包名 `astock`）。数据：沪深300+中证500 成分股 10 年日线（`~/.astock/astock.db`，约 800 只，168 万行，新浪接口）+ 指数日线（`index_daily` 表）+ 实时报价（新浪秒级）。

命令：`astock update / iterate / recommend / report / quote`。
研究脚本：`scripts/`（variant_study 变体矩阵、regime_switch_study 切换实验、portfolio_sim 组合模拟、strategy_lab、asof_backtest）。

## 当前系统配置（2026-08-14 起生效）

- 短线策略池：momentum / ma_trend / ma_trend_vol / volume_price；长线：value
- 回测规则：信号次日开盘买；短线持 15 交易日、**-10% 止损**；费用买 0.03% 卖 0.13%
- **regime 过滤**：沪深300 收盘 < 60 日均线 → 短线空仓观望（长线 value 不过滤）
- 仓位：单票为净值 10%（按胜率 5%~15% 映射），最多 10 只
- 每月跑 `iterate` 赛马，每周看 `report` 样本外命中率

## 决策铁律（防过拟合）

1. 一次只改一个变量；2. 必须多年份（10 年逐年）多数改善才合入，仅近期好的一律拒绝；
3. 合入后 `report` 真实命中率是最终裁判；4. 研究不动主程序，合入需用户拍板。
