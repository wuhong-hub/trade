# A 股量化推荐 CLI 工具设计文档

日期：2026-08-12
状态：已获用户确认

## 1. 目标

一个本地命令行工具（Python 包，命名为 `astock`），实现：

- 自动获取 A 股行情与财务数据（akshare，免费无需 token）
- 内置经典量化策略库，用历史数据回测验证策略有效性
- 手动触发迭代：滚动回测对策略排名，选出当前最优策略
- 用户询问时（`recommend` 命令）给出推荐：买入清单 + 理由 + 仓位风控建议 + 策略近期表现摘要
- 记录历史推荐并跟踪事后实际表现

## 2. 关键决策（已与用户确认）

| 决策点 | 结论 |
|---|---|
| 使用形态 | 本地命令行工具 |
| 策略生成方式 | 经典量化策略库 + 回测优选（不接 LLM） |
| 持有周期 | 短线波段与长线价值两套策略并存，推荐分开列出 |
| 数据源 | akshare（免费） |
| 迭代机制 | 手动触发（`iterate` 命令） |
| 选股范围 | 沪深300 + 中证500 成分股（约 800 只），名单随指数调整自动更新 |
| 回测/信号引擎 | pandas 向量化自研引擎（不用 backtrader/vectorbt） |
| 回测窗口 | 最近 2 年，分 4 个半年窗口滚动回测，取平均绩效排名 |
| 仓位规则 | 单只 10% 起步，按策略近期胜率 ±5% 浮动 |

## 3. 架构与模块划分

```
astock/
├── data/          # 数据层：akshare 抓取 + 本地缓存
│   ├── fetcher.py     # 拉日线行情、财务指标、指数成分股名单（带限速重试）
│   └── store.py       # SQLite 读写，增量更新（只拉新交易日）
├── strategies/    # 策略库：每个策略一个文件，统一接口
│   ├── base.py        # Strategy 基类
│   ├── momentum.py    # 动量突破（短线）
│   ├── ma_trend.py    # 双均线趋势（短线）
│   ├── volume_price.py# 量价配合（短线）
│   └── value.py       # 低PE+高ROE 价值筛选（长线）
├── backtest/
│   └── engine.py      # 信号→模拟交易→绩效指标
├── recommend/
│   └── engine.py      # 用当前最优策略扫描全池→推荐清单
├── tracker/
│   └── tracker.py     # 记录推荐，事后对照实际涨跌算命中率
└── cli.py         # 命令行入口：update / iterate / recommend / report
```

模块间只通过定义好的数据接口（DataFrame / dataclass）通信。

### 命令

- `astock update` — 增量更新本地数据（成分股名单、日线、财务指标）
- `astock iterate` — 滚动回测所有策略并排名，把短线/长线各自最优策略写入 `state.json`（含完整排名表与日期），迭代历史追加保存
- `astock recommend` — 用当前最优策略扫描股票池，输出推荐
- `astock report` — 历史推荐的实际表现（命中率、平均收益）

## 4. 策略接口与内置策略

策略是纯函数：输入单只股票的日线 DataFrame（开高低收、成交量；长线策略另加财务指标），输出每日信号（买入/持有/卖出）。不碰网络、不碰磁盘。回测与实盘推荐复用同一份策略代码，只是输入数据的时间截点不同。

首批 4 个策略：

- **动量突破（短线）**：20 日新高 + 成交量放大
- **双均线趋势（短线）**：5/20 日均线金叉买入、死叉卖出
- **量价配合（短线）**：缩量回调后放量反弹
- **价值筛选（长线）**：低 PE 分位 + ROE 连续达标 + 营收增长，季度级调仓

各策略的具体阈值参数（如均线周期、PE 分位点、ROE 年限）在实现计划中逐一确定。

## 5. 回测规则

刻意保持简单明确：

- 信号出现次日开盘价买入
- 短线：持有最多 10 个交易日，或触发 -7% 止损
- 长线：按季度信号调仓
- 费用：佣金 0.03%，卖出印花税 0.1%
- 绩效指标：胜率、年化收益、最大回撤、夏普比率

滚动回测：最近 2 年数据分 4 个半年窗口分别回测，取各窗口平均绩效排名，避免策略只靠一段行情吃分。

## 6. 推荐输出

`recommend` 输出包含：

- 买入清单：代码/名称、入选理由（触发的具体信号）、当前价；短线与长线分开列出
- 仓位与风控：单只建议仓位（10% 起步按胜率 ±5% 浮动）、止损/止盈价位（由策略信号给出，如跌破 20 日均线止盈）
- 策略表现摘要：当前所用策略近期回测的胜率、收益率、最大回撤
- 固定声明："仅为量化策略参考，不构成投资建议"

推荐记录落库，`report` 命令对照之后实际涨跌给出命中率和平均收益。

## 7. 数据层

SQLite 三张表：

- 日线行情（代码、日期、开高低收、成交量）
- 财务指标（代码、报告期、PE、ROE、营收增速）
- 指数成分股名单

`update` 为增量更新：查每只股票本地最后日期，只拉之后交易日；成分股名单每次刷新。首次全量约 800 只 × 2~3 年日线，预计几分钟到十几分钟（akshare 有频率限制，fetcher 带限速和重试）。

## 8. 错误处理

原则：单点失败不拖垮整体，但让用户看得见。

- 单只股票抓取失败：重试 3 次仍失败则跳过并警告，结束汇总"N 成功 / M 失败"
- 数据缺失（停牌、新股不满窗口期）：策略计算跳过该股，不产生信号
- akshare 接口失效：报错指明具体接口，提示升级 akshare
- `recommend` 时本地数据超过 3 个交易日未更新：明显提醒先跑 `update`
- 未跑过 `iterate` 就跑 `recommend`：报错提示先迭代

## 9. 测试

pytest，三层：

- 策略单元测试：人造 K 线（确定的金叉、突破形态），断言信号日期正确
- 回测引擎测试：人造数据 + 手算预期，验证胜率、回撤等指标
- 集成测试：mock akshare，跑通 update → iterate → recommend 全流程
